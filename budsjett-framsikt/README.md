# Kristiansand Kommune & Framsikt Documentation Deployment Package

Dette arkivet inneholder den komplette dokumentasjonspakken for kommunal økonomi, budsjettering, KOSTRA-kontering og Framsikt-arbeidsflyt.

## Innhold
1. `budsjettering-kristiansand-kommune-v2.md`: Overordnede rammer, måltall, handlingsregler og årshjul for Kristiansand kommune.
2. `lonnsbudsjettering-kristiansand-framsikt-v2.md`: Stillings- og lønnsbudsjettering i Framsikt, fast vs. variabel lønn, Excel-eksport/import og sjekkliste for pensjon/AGA.
3. `kostra-artskontoer-konteringsregler-framsikt.md`: Konteringsregler for lønn, sosiale utgifter og refusjoner (1000/1600/1700-serien).
4. `driftsarter-og-selvkost-alle-omrader-framsikt.md`: Driftsarter (1100-1480), selvkostberegninger (Vann, Avløp, Renovasjon, Byggesak) og KOSTRA-matrise for alle kommunalområder.

Generert for distribusjon og distribusjonsrigg (Antigravity).
