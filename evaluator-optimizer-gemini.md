# Evaluator-Optimizer Loop Specification: Google Gemini

This document provides a production specification and implementation blueprint for building an **Evaluator-Optimizer (Generator-Critic)** loop powered by **Google Gemini** models.

---

## 1. Architectural Overview

The Evaluator-Optimizer pattern improves LLM outputs by decoupling candidate generation from quality assessment. Rather than relying on a single-pass response, a fast **Generator** creates an initial output, while an authoritative **Evaluator** scores the output against explicit criteria. If quality gates are not met, both the previous draft and the critique are fed back to the Generator for iterative refinement.

```
                      ┌─────────────────────────────────┐
                      │        User Task Prompt         │
                      └────────────────┬────────────────┘
                                       │
                                       ▼
                      ┌─────────────────────────────────┐
                      │    Generator: Gemini 2.5 Flash  │◄──────────┐
                      │    (High throughput, fast draft)│           │
                      └────────────────┬────────────────┘           │
                                       │                            │
                                       ▼                            │ Refinement:
                      ┌─────────────────────────────────┐           │ Previous Draft +
                      │    Evaluator: Gemini 2.5 Pro    │           │ Strengths (preserve) +
                      │    (Strict Rubric + Pydantic)   │           │ Missing Elements +
                      └────────────────┬────────────────┘           │ Actionable Critique
                                       │                            │
                            Passes Quality Gates?                   │
                            (Score >= Pass Threshold)               │
                            ┌──────────┴──────────┐                 │
                      Yes   │                     │   No            │
                            ▼                     └─────────────────┘
                   [Accepted Output]
```

---

## 2. Gemini-Specific Architectural Capabilities

1. **Model Tier Heterogeneity**:
   - **Generator (`gemini-2.5-flash`)**: Sub-second TTFT (Time-To-First-Token) and high throughput for generating candidate solutions and rapid revisions.
   - **Evaluator (`gemini-2.5-pro`)**: Advanced multi-step reasoning, deep structural analysis, and adherence to complex grading rubrics.
2. **Native Pydantic Structured Output**:
   - Uses Gemini's `response_mime_type="application/json"` and `response_schema` to guarantee that the Evaluator returns valid, strongly-typed JSON critiques accessible directly via `response.parsed`.
3. **Preserving Loop State (Draft + Critique)**:
   - When revising in iteration $k > 1$, the Generator prompt must receive the **original task**, the **previous draft**, the **elements to preserve**, and the **missing components to fix**. This prevents context amnesia and avoids having the model restart from scratch.
4. **Thinking Budget Configuration**:
   - For complex verification tasks, `thinking_config` can be enabled on Pro models to allocate reasoning tokens prior to emitting the structured critique.
5. **System Instructions Isolation**:
   - Separate `system_instruction` contexts are configured for the Generator and Evaluator instances, enforcing distinct personas and preventing cross-role bias.

## 3. Prompts & Schemas

### Evaluator Response Schema (Pydantic)
```python
from pydantic import BaseModel, Field
from typing import List

class EvaluationSchema(BaseModel):
    score: float = Field(
        ge=0.0,
        le=1.0,
        description="Overall quality score from 0.0 (unusable) to 1.0 (perfect)."
    )
    passed: bool = Field(
        description="True only if score meets or exceeds the pass threshold."
    )
    strengths: List[str] = Field(
        default_factory=list,
        description="Aspects of the candidate output that correctly meet requirements and should be preserved."
    )
    missing_elements: List[str] = Field(
        default_factory=list,
        description="Required components, edge cases, or standards missing from the output."
    )
    actionable_critique: str = Field(
        description="Concrete, actionable instructions for the Generator on how to fix deficiencies in the next attempt."
    )
```

### Evaluator System Instruction
```text
You are an expert Quality Evaluator and System Auditor.
Your task is to critically analyze candidate outputs generated by an AI assistant.
Evaluate strictly against the provided task requirements, edge-case coverage, and domain standards.

Guidelines:
1. Be objective, thorough, and demanding. Do not award passing scores (>= 0.85) to flawed or partial solutions.
2. Highlight valid parts in 'strengths' so they are not accidentally lost during revision.
3. List explicit missing requirements in 'missing_elements'.
4. Provide concrete, actionable fixes in 'actionable_critique'.
```

### Generator System Instruction
```text
You are an expert AI engineer and solution generator.
Your job is to solve the user's task accurately and thoroughly.
When provided with an evaluation critique of your previous draft, preserve the identified strengths, correct all stated deficiencies, and deliver an improved, complete solution.
```

## 4. Production Python Implementation (Gemini SDK)

```python
import os
import logging
from typing import Optional, Dict, Any, List
from pydantic import BaseModel, Field
from google import genai
from google.genai import types

logging.basicConfig(level=logging.INFO, format="%(asctime)s [%(levelname)s] %(message)s")


# 1. Define Structured Output Schema for Evaluator
class EvaluationSchema(BaseModel):
    score: float = Field(
        ge=0.0,
        le=1.0,
        description="Overall quality score from 0.0 (unusable) to 1.0 (perfect)."
    )
    passed: bool = Field(
        description="True only if score meets or exceeds the pass threshold."
    )
    strengths: List[str] = Field(
        default_factory=list,
        description="Aspects of the candidate output that correctly meet requirements and should be preserved."
    )
    missing_elements: List[str] = Field(
        default_factory=list,
        description="Required components, edge cases, or standards missing from the output."
    )
    actionable_critique: str = Field(
        description="Concrete, actionable instructions for the Generator on how to fix deficiencies."
    )


class GeminiEvaluatorOptimizer:
    def __init__(
        self,
        api_key: Optional[str] = None,
        generator_model: str = "gemini-2.5-flash",
        evaluator_model: str = "gemini-2.5-pro",
        pass_threshold: float = 0.85,
        max_iterations: int = 4,
    ):
        self.client = genai.Client(api_key=api_key or os.environ.get("GEMINI_API_KEY"))
        self.generator_model = generator_model
        self.evaluator_model = evaluator_model
        self.pass_threshold = pass_threshold
        self.max_iterations = max_iterations

    def run(self, task_prompt: str) -> Dict[str, Any]:
        candidate_output = ""
        latest_critique: Optional[EvaluationSchema] = None
        iteration_history = []

        for iteration in range(1, self.max_iterations + 1):
            logging.info(f"--- Iteration {iteration}/{self.max_iterations} ---")

            # Step A: Generation / Revision
            if iteration == 1:
                gen_prompt = (
                    f"Task Requirement:\n{task_prompt}\n\n"
                    "Produce a complete, robust, and accurate solution fulfilling all requirements."
                )
            else:
                strengths_str = "\n".join(f"- {s}" for s in latest_critique.strengths) or "- None noted"
                missing_str = "\n".join(f"- {m}" for m in latest_critique.missing_elements) or "- None noted"

                gen_prompt = (
                    f"Original Task Requirement:\n{task_prompt}\n\n"
                    f"Previous Candidate Solution (Attempt {iteration - 1}):\n"
                    f"--- BEGIN PREVIOUS DRAFT ---\n{candidate_output}\n--- END PREVIOUS DRAFT ---\n\n"
                    f"Strengths to Preserve:\n{strengths_str}\n\n"
                    f"Deficiencies to Fix:\n{missing_str}\n\n"
                    f"Actionable Critique:\n{latest_critique.actionable_critique}\n\n"
                    "Deliver an improved, complete revised solution. Address all critique points "
                    "while preserving correct components from the previous attempt."
                )

            logging.info(f"Generating candidate response via [{self.generator_model}] (Iteration {iteration})...")
            gen_response = self.client.models.generate_content(
                model=self.generator_model,
                contents=gen_prompt,
                config=types.GenerateContentConfig(
                    system_instruction=(
                        "You are an expert AI solution generator. Fulfill the task thoroughly, "
                        "address feedback rigorously, and preserve valid components."
                    ),
                    temperature=0.7,
                ),
            )
            candidate_output = gen_response.text

            # Step B: Evaluation with Typed Pydantic Schema
            eval_prompt = (
                f"Original Task Requirement:\n{task_prompt}\n\n"
                f"Candidate Solution to Evaluate:\n[BEGIN CANDIDATE]\n{candidate_output}\n[END CANDIDATE]\n\n"
                f"Evaluate if this candidate satisfies the task. Minimum pass score is {self.pass_threshold}."
            )

            logging.info(f"Evaluating candidate response via [{self.evaluator_model}]...")
            eval_response = self.client.models.generate_content(
                model=self.evaluator_model,
                contents=eval_prompt,
                config=types.GenerateContentConfig(
                    system_instruction=(
                        "You are a strict, objective Quality Evaluator and System Auditor. "
                        "Critique the candidate solution and return a typed, structured assessment."
                    ),
                    temperature=0.1,
                    response_mime_type="application/json",
                    response_schema=EvaluationSchema,
                ),
            )

            # Step C: Parse & Validate Evaluation
            latest_critique: EvaluationSchema = eval_response.parsed
            logging.info(
                f"Evaluator Score: {latest_critique.score:.2f} | "
                f"Passed Flag: {latest_critique.passed} | "
                f"Identified Deficiencies: {len(latest_critique.missing_elements)}"
            )

            iteration_history.append({
                "iteration": iteration,
                "score": latest_critique.score,
                "passed": latest_critique.passed,
                "strengths": latest_critique.strengths,
                "missing_elements": latest_critique.missing_elements,
                "actionable_critique": latest_critique.actionable_critique,
            })

            # Step D: Strict Quality Gate Check
            if latest_critique.score >= self.pass_threshold:
                logging.info(f"✅ Quality threshold ({self.pass_threshold}) met at iteration {iteration}!")
                return {
                    "status": "success",
                    "iterations": iteration,
                    "final_score": latest_critique.score,
                    "output": candidate_output,
                    "history": iteration_history,
                }

            logging.warning(
                f"⚠️ Iteration {iteration} failed quality gate (Score {latest_critique.score:.2f} < {self.pass_threshold}). "
                f"Critique: {latest_critique.actionable_critique}"
            )

        logging.warning("Reached max iterations without reaching pass threshold. Returning latest candidate output.")
        return {
            "status": "max_iterations_reached",
            "iterations": self.max_iterations,
            "final_score": latest_critique.score if latest_critique else 0.0,
            "output": candidate_output,
            "history": iteration_history,
        }


# Example Usage
if __name__ == "__main__":
    # Initialize harness (requires GEMINI_API_KEY environment variable)
    harness = GeminiEvaluatorOptimizer(
        generator_model="gemini-2.5-flash",
        evaluator_model="gemini-2.5-pro",
        pass_threshold=0.85,
        max_iterations=3,
    )
    # result = harness.run("Write a Python function to parse and validate JWT tokens with ed25519 signatures.")
    # print(f"Result Status: {result['status']}, Final Score: {result['final_score']}")
```
